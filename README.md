# ECOUNT ERP 시급자 급여 자동정산 프로그램

S1(세콤) 출퇴근 기록을 기반으로 시급자 근무시간을 계산하고,
ECOUNT ERP 급여 입력용 엑셀 파일을 자동 생성하는 Python 프로그램입니다.

## 배경

- 합병(2026.04.30) 이후 ECOUNT ERP를 메인 급여시스템으로 사용
- S1(세콤) 출퇴근 단말기 사용 중
- 시급자가 많아 매월 근무시간 계산 및 수당 정산 자동화 필요
- ECOUNT 자체 야간수당 설정 한계로, 외부에서 계산 후 결과값만 ECOUNT에 입력하는 방식 채택

## 업무 흐름

```
S1 출퇴근 기록 (엑셀)
         |
    자동화 프로그램
         |
  ┌──────┴──────┐
  │             │
근무시간 계산   오류 검증
  │
수당 계산 (기본/연장/야간/휴일/주휴)
  │
ECOUNT 입력용 엑셀 생성
  │
ECOUNT 급여대장 입력 → 급여지급 / 명세서 발행
```

- pip

## 준비 파일

`data/` 폴더에 아래 3개 엑셀 파일을 준비하세요.

| 파일명 | 출처 | 필수 컬럼 |
|--------|------|----------|
| `s1_attendance.xlsx` | S1 출퇴근기록 다운로드 | 사번, 이름, 일자, 시간 |
| `ecount_employees.xlsx` | ECOUNT > 인사 > 사원정보 > 엑셀 다운로드 | 사번, 이름, 부서, 입사일, 퇴사일 |
| `hourly_rates.xlsx` | 직접 작성 | 사번, 이름, 시급 |

## 실행

```bash
python main.py
```

## 생성 파일

실행 후 `output/` 폴더에 다음 파일이 생성됩니다.

| 파일명 | 용도 |
|--------|------|
| `ECOUNT_입력용_YYYYMMDD.xlsx` | ECOUNT 급여항목 입력용 |
| `급여검증_오류리스트_YYYYMMDD.xlsx` | 확인 필요 항목 목록 |
| `급여마감_체크리스트_YYYYMMDD.xlsx` | 월 급여 마감 전 체크리스트 |
| `부서별_급여집계_YYYYMMDD.xlsx` | 경영진 보고용 집계 |

## 수당 계산 기준 (근로기준법 기준, 5인 이상 사업장)

| 수당 | 계산 기준 |
|------|----------|
| 기본급 | 기본근로시간(일 8시간 이내) × 시급 |
| 연장근로수당 | 연장시간 × 시급 × 1.5 |
| 야간근로수당 | 야간시간(22:00~06:00) × 시급 × 0.5 추가 |
| 휴일근로수당 | 휴일 8시간 이내 × 시급 × 1.5, 초과분 × 2.0 |
| 주휴수당 | 주 15시간 이상 근무 시 주 8시간 × 시급 |

## 오류 자동 감지 항목

- 출퇴근 기록 누락 (출근만 있거나 퇴근만 있는 경우)
- 사번 불일치 (S1 기록에 있으나 ECOUNT에 없는 사번)
- 퇴사자 근무기록 존재
- 하루 12시간 초과 근무
- 시급 미등록자
- 주휴수당 대상자 미처리
